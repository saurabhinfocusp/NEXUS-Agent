Submit a sample

Submitting doesn't block on a previous run — start as many as you like; each is tracked independently below. Upload a histology/multiplex image and its matching spatial expression data — .h5ad, .loom, a 10x Genomics .h5 feature-barcode matrix, a zipped/tarred 10x mtx bundle, or matrix.mtx + barcodes.tsv + features.tsv selected together (multi-select, no zipping needed). Either file can also be plain-gzipped (e.g. image.tiff.gz, expression.h5ad.gz) — it's decompressed automatically. Seurat/SingleCellExperiment .rds files aren't read directly — convert to .h5ad first (e.g. SeuratDisk or sceasy::convertFormat). A 10x Genomics Loupe .cloupe file can't be read at all (no reader exists outside Loupe Browser itself) — upload the *_feature_bc_matrix.h5 or mtx bundle it was generated from instead. Real CellPose+VGG16 inference can take several minutes on CPU — this page polls in the background, no need to keep it in the foreground.
